# Tech with Iroh

Landing page for the *Tech with Iroh* podcast and live show.

## Getting started

```bash
npm install
npm run dev       # local dev server with hot reload
npm run build     # production build → dist/
npm run preview   # serve the production build
```

## Project structure

```
.
├── index.html, live.html, ctrl-build.html, sponsors.html   # Pages
├── vite.config.js             # Multi-page build + content plugin
├── scripts/
│   ├── fetch-content.mjs      # Pulls episodes/clips from YouTube + the podcast RSS
│   └── render.mjs             # Renders partials and content into the HTML at build time
├── public/                    # Static files (favicon, logo, images/iroh.jpg)
└── src/
    ├── data/
    │   ├── content.json       # Generated by fetch-content (committed as offline fallback)
    │   └── tiktok.json        # Hand-picked TikTok clips: [{ "id": "<video id>", "title": "…" }]
    ├── partials/              # head, nav, footer, newsletter, player — shared by every page
    ├── scripts/modules/       # nav, player, clips, episodeFilters, faq, newsletter
    └── styles/                # base / components / sections
```

## Content

Episodes are never edited by hand. `npm run dev` and `npm run build` run
`scripts/fetch-content.mjs` first, which pulls:

- **Video episodes and Shorts** from the YouTube channel feed (latest 15 uploads)
- **Audio episodes** from the Spotify for Creators RSS feed (full catalogue)

To feature TikTok clips, add their video IDs (the number at the end of a TikTok URL)
to `src/data/tiktok.json`. They appear first in the Clips rail.
Use `npm run build:offline` to build from the committed `content.json` without network.

## Conventions

- **CSS:** BEM-style classes (`block__element--modifier`); state classes use `is-*`.
  Design tokens live in `src/styles/base/variables.css`.
  Breakpoints: `960px` / `720px` / `420px`.
- **JS:** behaviour hooks via `data-*` attributes, never styling classes.
- **Deploy:** any static host (Netlify, Vercel, GitHub Pages) — build command `npm run build`, output `dist/`.
